# Frozen external-annotation benchmark

The nine families unresolved by the deposited sequence and structure searches should be rerun against independently versioned resources.

## Required search arms

1. Profile HMM search against a frozen Pfam release.
2. InterProScan with every member database and version recorded.
3. NCBI CDD/RPS-BLAST against a locally frozen database.
4. Profile–profile comparison against a frozen PDB/domain-profile collection.
5. Structure search of deposited predictions against a frozen structural database.

The query set, database archives or persistent identifiers, command lines, e-value/TM-score thresholds, coverage requirements, and raw top hits must be deposited. Annotation is assigned only when prespecified significance and coverage criteria agree; otherwise the result remains unresolved. Search dates alone are not reproducible substitutes for database versions.

Not rerun. The release contains summary results but not all query sequences, raw search outputs, or frozen external databases. No current-database result is claimed from the summary tables.
