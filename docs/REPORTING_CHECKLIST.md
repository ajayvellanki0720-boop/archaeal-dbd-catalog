# Reporting checklist

## Scope and claims

- [x] Title identifies a bounded catalog rather than a comprehensive archaeal regulome.
- [x] Abstract states the two-clan search universe and the experimental limitation.
- [x] “Noncanonical” is defined operationally as outside the nineteen-family reference set within CL0123/CL0057.
- [x] DNA-binding-domain assignment is distinguished from transcription-factor function.
- [x] Neighborhood associations are not called regulons.

## Sampling and validation

- [x] The 331-genome selection algorithm, caps, seed, and rationale are stated.
- [x] Alternative within-panel sampling schemes are reported.
- [x] Independent accessions are used for fixed-HMM projection validation.
- [x] Motif tests hold out genomes and genera.
- [x] Assembly/source-quality sensitivity is reported.
- [x] Genome-level prevalence uncertainty is recalculated with genus-clustered resampling.
- [x] Fixed-catalog observation and the five-genome eligibility rule are evaluated across 10 to 100 percent of the lineage-stratified panel.
- [x] Released-sequence family separability is evaluated with complete-genus holdout across the full catalog.
- [x] Motif enrichment is re-evaluated by holding out each eligible major lineage.
- [ ] De novo family discovery has been repeated on independent panels (blocked by missing raw inputs).
- [x] Complete-genus composition holdout has been attempted for all 250 families; 245 are evaluable and five are reported as unevaluable.
- [ ] Family assignment has been calibrated with taxonomically blocked HMM fitting, explicit negatives, and score thresholds.
- [ ] Direct DNA binding and regulatory function have been experimentally tested.

## Reproducibility

- [x] Software dependencies and external tool versions are pinned where known.
- [x] Random seeds and runnable commands are documented.
- [x] A minimal worked example and automated tests are included.
- [x] A checksum manifest is included.
- [x] Continuous integration runs tests, smoke checks, reference auditing, the complete released analysis, and checksum verification.
- [x] Unavailable extended analyses have preregistered protocols and a machine-readable status registry.
- [x] The 3,192-versus-3,526 matrix scope is explicit.
- [x] Missing source tables and database provenance fields are listed.
- [x] Repository visibility is public.
- [x] An immutable archive DOI has been minted; the stable concept DOI is 10.5281/zenodo.23461089.

## Submission metadata

- [x] Author contributions, funding, competing interests, ethics, and data/code statements are drafted.
- [x] Main and supplementary figure captions state evidentiary limits.
- [x] A response-to-reviewers document and cover-letter draft are supplied.
- [x] Scientific Reports formatting and a journal-specific checklist have been applied.
