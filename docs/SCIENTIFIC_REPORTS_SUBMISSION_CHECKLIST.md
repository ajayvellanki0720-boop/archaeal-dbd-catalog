# Scientific Reports submission checklist

Checked against the official Scientific Reports submission guidelines and editorial policies on 19 October 2026.

## Article format

- [x] Title is a single scientifically accurate sentence fragment of fewer than 20 words.
- [x] Title page includes all authors, affiliation, contact information, equal-contribution statement, and corresponding-author markers.
- [x] Abstract is unstructured, contains no citations, and is 162 words (limit: 200 words).
- [x] Six keywords/key phrases are provided (limit: six).
- [x] Main text is single-column and left aligned.
- [x] Main text before Methods is approximately 2,950 words (recommended maximum: 4,500 words, excluding Abstract, Methods, References, and legends).
- [x] Continuous, high-contrast line numbers are included in the left margin.
- [x] Arabic page numbers appear in the footer.
- [x] Six figures and one table appear in the main manuscript (display-item limit: eight).
- [x] The main table fits on one page and remains editable.
- [x] Figure legends are concise and below 350 words each.
- [x] Supplementary Information is a single file whose first page includes the manuscript title and author list.

## Reporting and reproducibility

- [x] The two-Pfam-clan discovery universe is explicit in the title, Abstract, Introduction, Results, Discussion, and Methods.
- [x] The manuscript states that the captured fraction of all archaeal DNA-binding-domain space cannot be estimated from the available data.
- [x] The 331-genome panel is defined as the result of an explicit lineage-aware rule rather than an independently selected target size.
- [x] Alternative panel resampling and independent-accession projection analyses are reported with their inferential limits.
- [x] The former ambiguous “regulatory region” language is replaced with the aligned protein-domain interval and an exact reciprocal-exclusion rule.
- [x] The inherited 5-bit tolerance is identified as operational and not prospectively calibrated.
- [x] Complete family filtering criteria, including the nonregulatory exclusion patterns, are reported in Supplementary Methods.
- [x] DNA-binding-domain assignment, candidate-regulator evidence, and experimentally demonstrated transcription-factor function are distinguished.
- [x] Genome-, genus-, and major-lineage-blocked motif analyses are distinguished and interpreted descriptively.
- [x] Data gaps and differences between the 3,192- and 3,526-genome artifacts are disclosed.
- [x] Exact known software versions are reported, while unavailable historical database releases are not inferred.
- [x] Generative-AI assistance is disclosed in Methods together with author verification and responsibility.
- [x] Ethics applicability is stated in Methods.

## End matter and files

- [x] Data Availability and Code Availability are separate sections before References.
- [x] The GitHub repository, MIT license, immutable version 0.4.0 archive, and Zenodo DOI are provided.
- [x] The Zenodo software/data release is cited in the numbered reference list.
- [x] References use numerical square-bracket citations and a Nature-style bibliography populated from DOI metadata.
- [x] Acknowledgements/funding, author contributions, and competing interests are provided.
- [x] The cover letter explains journal fit, the peer-review-driven restructuring, corresponding-author contacts, prior editor discussions, and reviewer preferences/exclusions.
- [x] Manuscript, Supplementary Information, and cover letter were rendered and visually inspected page by page.
- [x] Document metadata were privacy-scrubbed.

## Remaining scientific limitations (not formatting defects)

- The full 1,069-genome candidate pool and raw discovery HMM hit tables are unavailable, preventing a complete de novo rediscovery analysis across alternative panels.
- Corrected 3,526-genome summary tables are available, but the accession-resolved raw matrices cover the earlier 3,192-genome projection.
- Several dependence-corrected source tables and complete sequences for all 250 families were not preserved.
- Computational evidence prioritizes candidates but cannot replace direct DNA-binding and in vivo regulatory experiments.
